# Frequency-Domain-Based Acceleration of CNN on FPGA

Hermitian-symmetric OaA-FFT convolution accelerator for 2D CNN edge
inference, targeting the Terasic DE10-Standard (Intel Cyclone V SoC).

## Repository layout

### `docs/`

| Path | Contents |
|---|---|
| `docs/notes/` | Theory and study notes: DSP fundamentals, linear vs circular convolution, inference vs training. |
| `docs/design/` | Stable design decisions and links to the Notion boards. |

### `phase1_matlab/` — Algorithmic verification

| Path | Contents |
|---|---|
| `src/` | `.m` scripts. |
| `functions/` | Helper functions called by `src/`. |
| `results/` | Plots and numerical tables. Small files only; anything large is regenerated by script rather than committed. |

### `phase2_rtl/` — Hardware implementation

| Path | Contents |
|---|---|
| `simulink/` | The OaA CORE. |
| `hdl/src/` | Verilog sources, both Simulink-generated and hand-written. |
| `hdl/tb/` | Testbenches. Kept separate because they are not synthesized and the toolchain needs a clean source list. |
| `sim/` | Simulation run scripts: Questa `.do` files and waveform setups. Code lives in `hdl/`, how to run it lives here. |
| `vectors/` |  Reference inputs and outputs from MATLAB/Simulink that the testbenches check against "IF NEEDED". |
| `quartus/` | Project files only: `.qpf`, `.qsf`, `.sdc`, Qsys. B. |

### `hps/src/`

C code running on the ARM processor inside the SoC. Maps physical memory,
writes accelerator registers, reads results back.

### `scripts/`

General workflow helpers, Not part of the design itself.
